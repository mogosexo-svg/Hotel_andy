# Fotos del Hotel Andy

Pon aquí las fotos **originales** (sin comprimir, sin filtros de WhatsApp). La web las optimiza sola.
Nombre: `<lugar>-<n>.jpg`, por ejemplo `piscina-1.jpg` o `hab-familiar-2.jpg`.

| Prioridad | Lugar | Nombre | Para qué |
|---|---|---|---|
| 🔴 | Piscina de día, horizontal | `piscina-1..3` | Portada (hero) |
| 🔴 | Piscina de noche (abre hasta la 01:00) | `piscina-noche-1` | Diferenciador |
| 🔴 | Fachada | `fachada-1` | Cómo llegar / Google Maps |
| 🔴 | Una de cada tipo de habitación (7 tipos) | `hab-doble-sencilla-1`, `hab-doble-deluxe-1`, `hab-triple-1`, `hab-triple-deluxe-1`, `hab-cuadruple-1`, `hab-familiar-1`, `hab-suite-1` | Tarjetas de habitaciones |
| 🟡 | Baño | `bano-1` | Galería |
| 🟡 | Playa cercana / camino a la playa | `playa-1..2` | "A pasos de la playa" |
| 🟡 | Vista desde los pisos altos / suite | `vista-1` | Suite |
| 🟢 | Parqueadero, recepción, áreas comunes | `areas-1..n` | Galería |
| 🟢 | Logo (si existe), en PNG o SVG | `logo.svg` | Marca |

Reglas (hallmark): **nunca inventar fotos del hotel.** Si falta una, se usa una foto con licencia libre de Atacames de la librería de hallmark (Wikimedia, con crédito) **solo** para la playa o el pueblo, nunca para cuartos o piscina.
